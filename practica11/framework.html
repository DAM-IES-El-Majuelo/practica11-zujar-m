Backend con Node.js

El Backend maneja la lógica de la aplicación, la base de datos y las peticiones HTTP. Con Node.js, utilizamos frameworks como Express.js para construir servidores rápidos y eficientes.

En esta sección, veremos cómo crear un servidor básico con Node.js y Express.js.

Ejemplo de Express.js (Backend)

const express = require('express');
const app = express();

app.get('/', (req, res) => {
    res.send('¡Hola desde el Backend con Node.js!');
});

app.listen(3000, () => {
    console.log('Servidor corriendo en http://localhost:3000');
});

Ventanas de Navegador (Viewport)

El Viewport es el área visible en la pantalla donde se renderiza la aplicación. Es crucial tener en cuenta el tamaño de la ventana del navegador para crear aplicaciones web responsivas.

Veamos cómo cambiar el diseño de una página según el tamaño del viewport.

Ejemplo de Responsividad (Viewport)

/* CSS para viewport */
@media screen and (max-width: 768px) {
    .responsive-container {
        background-color: lightblue;
    }
}

@media screen and (min-width: 769px) {
    .responsive-container {
        background-color: lightgreen;
    }
}

Este fondo cambia de color dependiendo del tamaño de la ventana del navegador.
