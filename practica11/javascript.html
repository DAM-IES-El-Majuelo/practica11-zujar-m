¿Qué es JavaScript?

JavaScript es un lenguaje de programación de alto nivel utilizado principalmente para crear interactividad en páginas web. Es uno de los tres pilares fundamentales de la web, junto con HTML y CSS.

JavaScript permite manipular el DOM (Document Object Model), responder a eventos de los usuarios, y mucho más. Es un lenguaje interpretado, lo que significa que el código se ejecuta de forma inmediata en el navegador sin necesidad de ser compilado.
